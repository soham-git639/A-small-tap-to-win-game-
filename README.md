🎮 Simple Java Console Game

This is a small Java console game built using basic OOP concepts. It demonstrates user input handling, simple game logic, and randomization — ideal for beginners learning Java programming.

🚀 How to Run

Open the project in VS Code or any Java IDE.

Compile and run:

javac Game.java App.java
java App


Follow the on-screen instructions to play.

🧩 Features

Written entirely in Java.

Console-based interaction.

Simple and easy-to-understand logic for learning purposes.
